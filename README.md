# ঢাকার বাস ভাড়া

ঢাকার যেকোনো জায়গা থেকে যেকোনো জায়গায় **কোন কোন বাস যায়**, **কত কিলোমিটার**
আর **সরকারি ভাড়া কত** — ম্যাপে দেখা যায়। বাংলা ও ইংরেজি দুইভাবেই খোঁজা যায়:
`যাত্রাবাড়ী` লিখলেও আসে, `jatrabari` লিখলেও।

সাইটে কোনো সার্ভার লাগে না — একটা HTML, একটা CSS, একটা JS আর একটা JSON।
GitHub Pages-এ `site/` ফোল্ডারটা রাখলেই চলে।

## এখন কী কী আছে

| | |
|---|---|
| স্টপেজ | ২৪৬ |
| বাস | ১৫৬ |
| সরকারি ভাড়ার চার্ট সহ রুট | ৪৭ |
| ভাড়ার হার | বাস ৳২.৫৩/কিমি (সর্বনিম্ন ৳১০), মিনিবাস ৳২.৪৩/কিমি (সর্বনিম্ন ৳৮) |
| হার কার্যকর | ২৩ এপ্রিল ২০২৬ |

- **রুট খুঁজুন** — দুই জায়গা দিলে সরাসরি বাসের তালিকা, দূরত্ব ও ভাড়া। সরাসরি
  বাস না থাকলে "এক বার বাস বদলে" যাওয়ার বিকল্প, কোথায় নামতে হবে সহ।
- **সব বাস ও স্টপেজ** — ১৫৬টা বাসের পুরো স্টপেজ তালিকা, প্রতিটার দূরত্ব ও ভাড়া।
- **ভাড়া চার্ট দেখুন** — বিআরটিএ-র প্রকাশিত আসল চার্টের ছবি, ওই রুটেরটাই।
- **অভিযোগ** — ভাড়া বেশি চাইলে বিআরটিএ ১৬১০৭ / ভোক্তা অধিকার ১৬১২১ / ৯৯৯।

## দূরত্ব কীভাবে মাপা — আর কেন OSRM-এর সংখ্যা সরাসরি নেওয়া হয়নি

প্রথমে পুরো রুটটা (সব স্টপেজ ওয়েপয়েন্ট ধরে) OSRM-এ পাঠানো হয়েছিল। ফল ভুল
এলো — **প্রায় দ্বিগুণ**:

```
মিরপুর-১২ → মতিঝিল
   বিআরটিএ-র চার্ট          ১৫.৩ কিমি
   OSRM, সব স্টপেজ ওয়েপয়েন্ট  ২৬.৩ কিমি   ← ভুল
   OSRM, শুধু দুই প্রান্ত      ১৫.২ কিমি   ← ঠিক
```

কারণ: প্রতিটা ওয়েপয়েন্টে গাড়িটাকে *হুবহু* থামাতে হয়। স্টপেজের বিন্দু যদি
ডিভাইডারের উল্টো পাশে বা ফ্লাইওভারের উপর পড়ে, OSRM পরের ইউ-টার্ন পর্যন্ত
গিয়ে ঘুরে আসে। ২১টা স্টপেজে সেই বাড়তি পথ জমে দূরত্ব ফুলে যায়।

তাই এখন **সরলরেখার চেইন × ১.১০** ধরা হয় (`CIRCUITY`, `tools/04_build.py`),
আর OSRM যদি তার চেয়ে কম বলে তখন OSRM-এর কথাই মানা হয়। বিআরটিএ-র ৩০টা
চার্টের সাথে মিলিয়ে দেখা গেছে হেরফের **গড়ে ১৪%**। OSRM-এর geometry শুধু
ম্যাপে লাইন আঁকতে ব্যবহার হয় — ওটাই ওর ভালো কাজ।

## নাম খোঁজা কীভাবে কাজ করে

`site/app.js`-এর `fold()` প্রতিটা নামকে একটা "ধ্বনি-চাবি"তে বদলায়:

- বাংলা → ইংরেজি ধ্বনি (`যাত্রাবাড়ী` → `jatrabari`)
- বানানের হেরফের মেলানো (`ph↔f`, `z↔j`, `v↔bh`, `sh↔s`, দুইবার একই অক্ষর)
- সোজা মিল না পেলে তবেই বানান-ভুল ক্ষমা (edit distance)
- `tools/synonyms.json` — মানুষ যে নামে খোঁজে: `উত্তরা` → আজমপুর/হাউজ
  বিল্ডিং/জসীমউদ্দীন, `ঢাবি` → শাহবাগ, `NSU` → বসুন্ধরা

## ডেটা আবার বানাতে হলে

```bash
cd tools
python 01_canonicalize.py    # নাম পরিষ্কার, ডুপ্লিকেট মেলানো
python 02_geocode.py         # Nominatim থেকে lat/lon (ধীর, ক্যাশ করা)
python 02b_retry.py          # যেগুলো পাওয়া যায়নি, বিকল্প নামে
python 02c_fix.py            # ভুল জেলায় বসে যাওয়াগুলো
python 02e_snap.py           # OSM-এর আসল বাস স্টপে বসানো
python 02d_validate.py       # যাচাই — কোনটা এখনো ভুল জায়গায়
python 03_routes.py          # OSRM থেকে রুটের লাইন (ক্যাশ করা)
python 05_charts.py          # বিআরটিএ-র PDF → ছবি
python 06_match_charts.py    # কোন বাসের কোন চার্ট
python 04_build.py           # সব জোড়া দিয়ে site/data/data.json
```

`02d_validate.py` সবচেয়ে কাজের। এটাই ধরিয়ে দিয়েছে যে **কাকলী** শ্যামলীতে
বসে আছে, **কলেজ গেট** খিলগাঁওয়ে, আর **বিমানবন্দর** মহাখালীতে — কারণ ওসব
নামে ঢাকায় একাধিক জায়গা আছে। ঠিক করা অবস্থানগুলো `tools/overrides.json`-এ,
প্রতিটার পাশে কেন বদলানো হলো তা লেখা।

## যা এখনো ঠিক নয়

- দূরত্ব আনুমানিক — সরকারি চার্টের চেয়ে গড়ে ১৪% এদিক-ওদিক। যেখানে চার্ট
  আছে, চার্টটাই চূড়ান্ত।
- রুটের তালিকা busroutebd থেকে নেওয়া; বাস্তবে বাস কিছু স্টপেজ বাদ দিতে পারে,
  বা কোম্পানি রুট বদলাতে পারে।
- ১১২টা সরকারি চার্টের মধ্যে ৩৩টা কাজে লেগেছে। বাকিগুলোর দুই প্রান্তের নাম
  আমাদের স্টপেজ তালিকায় নেই (ইপিজেড, কাপাসিয়া, ইকুরিয়া…)।
- নীলা মার্কেট, জারুন, কুচিমুড়া — OpenStreetMap-এ নেই, তাই বাদ পড়েছে।
  অনুমান করে কোঅর্ডিনেট বসানো হয়নি।
