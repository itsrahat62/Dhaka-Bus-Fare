# ঢাকার বাস ভাড়া

ঢাকার যেকোনো জায়গা থেকে যেকোনো জায়গায় **কোন কোন বাস যায়**, **কত কিলোমিটার**
আর **সরকারি ভাড়া কত** — ম্যাপে দেখা যায়। বাংলা ও ইংরেজি দুইভাবেই খোঁজা যায়:
`যাত্রাবাড়ী` লিখলেও আসে, `jatrabari` লিখলেও।

সাইটে কোনো সার্ভার লাগে না — একটা HTML, একটা CSS, একটা JS আর একটা JSON।
GitHub Pages-এ `site/` ফোল্ডারটা রাখলেই চলে।

## এখন কী কী আছে

| | |
|---|---|
| স্টপেজ | ২৫১ |
| বাস | ২০৩ |
| সরকারি ভাড়ার চার্ট | ১১২ (৩,২৪৪ জোড়া স্টপেজের হুবহু ভাড়া) |
| ভাড়ার হার | বাস ৳২.৫৩/কিমি (সর্বনিম্ন ৳১০), মিনিবাস ৳২.৪৩/কিমি (সর্বনিম্ন ৳৮) |
| হার কার্যকর | ২৩ এপ্রিল ২০২৬ |

- **রুট খুঁজুন** — দুই জায়গা দিলে প্রথমেই **সরকারি ভাড়া**: বিআরটিএ-র চার্টে
  ওই দুই জায়গার ভাড়া যত রুটে লেখা আছে, সবগুলোই (রুট ভেদে পথ আলাদা, তাই
  ভাড়াও আলাদা)। তারপর সরাসরি বাসের তালিকা। সরাসরি বাস না থাকলে "এক বার
  বাস বদলে" যাওয়ার বিকল্প, কোথায় নামতে হবে সহ।
- **সব বাস** — ২০৩টা বাসের পুরো স্টপেজ তালিকা, প্রতিটার দূরত্ব ও ভাড়া।
- **সবার রিপোর্ট** — যাত্রীরা কোন বাস নিয়ে কী বলছেন, সবচেয়ে নতুনগুলো আগে।
- **ভাড়া চার্ট দেখুন** — বিআরটিএ-র প্রকাশিত আসল চার্টের ছবি, ওই রুটেরটাই।
- **অভিযোগ** — ভাড়া বেশি চাইলে বিআরটিএ ১৬১০৭ / ভোক্তা অধিকার ১৬১২১ / ৯৯৯।

## যাত্রীরাই বলবেন কোন বাস এখনো চলে

ঢাকায় বাস কোম্পানি বন্ধ হয়, রুট বদলায়, নতুন বাস নামে — আর **কোনো সরকারি
বা বেসরকারি তালিকা এত দ্রুত হালনাগাদ হয় না**। খুঁজে দেখা গেছে,
busroutebd-র বাইরে ঢাকার বাস রুটের কোনো টাটকা উৎস নেই; যে সাইটগুলো
"২০২৬-এর ডেটা" বলে দাবি করে, তাদেরটাও একই পুরোনো স্ক্র্যাপ।

তাই যাঁরা রোজ চড়েন, তাঁদেরই জিজ্ঞেস করা হয়:

- প্রতিটা বাসের পাশে **চলে / চলে না / জানি না** — এক চাপে জানানো যায়
- যে বাস নিয়ে বেশি মানুষ বলেছেন **চলে**, সে তালিকার **উপরে**
- যে বাস নিয়ে বেশি মানুষ বলেছেন **চলে না**, সে **সবার নিচে** ও ম্লান
- স্টাফের ব্যবহার, ভিড়, বাসের অবস্থা নিয়ে **রেটিং ও মন্তব্য**
- সবার দেওয়া মত **সবাই দেখতে পান** — বাসের পাতায় ও "সবার রিপোর্ট" ট্যাবে

লগইন লাগে না। Firebase-এর anonymous auth প্রতিটা ব্রাউজারকে একটা গোপন
আইডি দেয়, আর রিভিউ ডকুমেন্টের আইডি সেই uid — তাই **এক ফোন থেকে একটা
বাসে একটাই মত** যায় (মত বদলানো যায়, কিন্তু সংখ্যা বাড়ানো যায় না)।

সাইটের মাথায় সবসময় লেখা থাকে: *ঢাকায় বাস প্রতিনিয়ত যোগ হয়, বন্ধও হয় —
এখানকার তথ্যের উপর পুরোপুরি ভরসা করবেন না, আশেপাশের মানুষকে জিজ্ঞেস
করে নিন।*

### Firebase চালু করা (একবারই)

`site/firebase-config.js` খালি থাকলে সাইট চলবে, শুধু ভোট-রিভিউর অংশটা
লুকানো থাকবে। চালু করতে:

1. [console.firebase.google.com](https://console.firebase.google.com)-এ
   একটা প্রজেক্ট বানান (ফ্রি **Spark** প্ল্যানই যথেষ্ট)
2. **Firestore Database** → Create database → production mode
3. **Authentication** → Sign-in method → **Anonymous** চালু করুন
4. **Project settings → Your apps → Web** — যে config দেখাবে সেটা
   `site/firebase-config.js`-এ বসান
5. `firestore.rules` ফাইলের পুরোটা **Firestore → Rules**-এ পেস্ট করে Publish
6. `firestore.indexes.json`-এর ইনডেক্সটা বানান (নইলে "সবার রিপোর্ট" পাতা
   কাজ করবে না) — অথবা `npx firebase deploy --only firestore` চালান

> `firebase-config.js`-এর `apiKey` গোপন নয়। Firebase-এর ওয়েব কনফিগ সবসময়
> ব্রাউজারে যায়, গুগল নিজেই একে পাবলিক ধরতে বলে। আসল নিরাপত্তা আসে
> `firestore.rules` থেকে — কে কী লিখতে পারবে সেটা ওখানেই ঠিক হয়।

### নিজে যাচাই করা

আসল Firebase ছাড়াই লোকাল এমুলেটরে সব পরীক্ষা করা যায়:

```bash
npm install                 # শুধু firebase-tools (যাচাইয়ের জন্য)
npm run emulator            # Firestore + Auth এমুলেটর
npm run site                # আরেকটা টার্মিনালে
# তারপর http://127.0.0.1:8765/?emulator=1
```

`?emulator=1` থাকলে সাইট আসল Firebase-এর বদলে নিজের কম্পিউটারে যায়।
এভাবেই ভোটের হিসাব, মত বদলানো আর security rules যাচাই করা হয়েছে —
যেমন "অন্যের নামে লেখা", "রেটিং ১০০", "৫০০০ অক্ষরের মন্তব্য" — সবই
নিয়মে আটকায়।

### Firestore-এ কী কী জমা থাকে

```
summary/all
    { b: { <রুটের চাবি>: { r, n, u, rs, rc } } }
    r = চলে · n = চলে না · u = জানি না · rs = রেটিংয়ের যোগ · rc = কতজন
    সব বাসের হিসাব এক ডকুমেন্টে, তাই পাতা খুললে মাত্র একটা read লাগে

buses/<রুটের চাবি>/reviews/<uid>
    { v, rating, text, name, bus, at }
    ডকুমেন্টের আইডি uid — তাই এক ফোন, এক মত
```

রুটের চাবি (`k`) বাসের নাম থেকে বানানো, সূচক থেকে নয় — ডেটা আবার
তৈরি করলেও ভোট হারায় না।

## দূরত্ব কীভাবে মাপা — আর কেন OSRM-এর সংখ্যা সরাসরি নেওয়া হয়নি

প্রথমে পুরো রুটটা (সব স্টপেজ ওয়েপয়েন্ট ধরে) OSRM-এ পাঠানো হয়েছিল। ফল ভুল
এলো — **প্রায় দ্বিগুণ**:

```
মিরপুর-১২ → মতিঝিল
   বিআরটিএ-র চার্ট          ১৫.৩ কিমি
   OSRM, সব স্টপেজ ওয়েপয়েন্ট  ২৬.৩ কিমি   ← ভুল
   OSRM, শুধু দুই প্রান্ত      ১৫.২ কিমি   ← ঠিক
```

কারণ: প্রতিটা ওয়েপয়েন্টে গাড়িটাকে *হুবহু* থামাতে হয়। স্টপেজের বিন্দু যদি
ডিভাইডারের উল্টো পাশে বা ফ্লাইওভারের উপর পড়ে, OSRM পরের ইউ-টার্ন পর্যন্ত
গিয়ে ঘুরে আসে। ২১টা স্টপেজে সেই বাড়তি পথ জমে দূরত্ব ফুলে যায়।

তাই এখন **সরলরেখার চেইন × ১.১০** ধরা হয় (`CIRCUITY`, `tools/04_build.py`),
আর OSRM যদি তার চেয়ে কম বলে তখন OSRM-এর কথাই মানা হয়। বিআরটিএ-র ৩৪টা
চার্টের সাথে মিলিয়ে দেখা গেছে হেরফের **গড়ে ১৩%**। OSRM-এর geometry শুধু
ম্যাপে লাইন আঁকতে ব্যবহার হয় — ওটাই ওর ভালো কাজ।

## সরকারি ভাড়া — আন্দাজ নয়, চার্টের সংখ্যাই

বিআরটিএ-র ভাড়ার চার্ট স্ক্যান করা ছবি, ভেতরে স্টপেজ-থেকে-স্টপেজ ভাড়ার
বিশাল ছক। পুরো ছক তোলার দরকার নেই — কারণ ছকটা আসলে বাঁ পাশের
**কিলোমিটার কলাম** থেকেই বানানো:

```
ভাড়া = সর্বোচ্চ(১০, round(|কিমি_খ − কিমি_ক| × ২.৫৩))
```

চার্টের ১০টা ঘরের সাথে মিলিয়ে দেখা হয়েছে, **১০টাই মেলে**। তাই
`tools/09_chart_columns.py` প্রতিটা পাতার বাঁ দুই কলাম কেটে আনে,
সেগুলো পড়ে `data/chart-stops.json` লেখা হয় — **১১২টা চার্ট, ১২৮৩ সারি**।

তারপর `tools/10_resolve_charts.py` চার্টের নামগুলো আমাদের স্টপেজের সাথে
মেলায় (৯৩%; বাকিগুলো ইপিজেড, সফিপুরের মতো জায়গা যা আমাদের তালিকায়
নেই)। ফলে **৩,২৪৪ জোড়া স্টপেজের হুবহু সরকারি ভাড়া** বলা যায়।

**একটা ফাঁদ আছে:** এক নাম দুই জায়গা বোঝাতে পারে। "সোনারগাঁও" এক চার্টে
কারওয়ান বাজারের হোটেল, আরেক চার্টে নারায়ণগঞ্জের উপজেলা — ভুল ধরলে
মোহাম্মদপুর → কারওয়ান বাজার ৳৮৯ দেখাচ্ছিল। এখন দুই পাহারা:
`tools/chart-aliases.json`-এ দ্ব্যর্থক নাম ইচ্ছা করে বাদ, আর `04_build.py`
মিলিয়ে দেখে চার্টে লেখা দূরত্ব সরলরেখার চেয়ে কম কি না (রাস্তা সরলরেখার
চেয়ে ছোট হয় না) — বেমানান স্টপেজটা বাদ পড়ে, পুরো চার্ট নয়।

## নাম খোঁজা কীভাবে কাজ করে

`site/app.js`-এর `fold()` প্রতিটা নামকে একটা "ধ্বনি-চাবি"তে বদলায়:

- বাংলা → ইংরেজি ধ্বনি (`যাত্রাবাড়ী` → `jatrabari`)
- বানানের হেরফের মেলানো (`ph↔f`, `z↔j`, `v↔bh`, `sh↔s`, দুইবার একই অক্ষর)
- সোজা মিল না পেলে তবেই বানান-ভুল ক্ষমা (edit distance)
- `tools/synonyms.json` — মানুষ যে নামে খোঁজে: `উত্তরা` → আজমপুর/হাউজ
  বিল্ডিং/জসীমউদ্দীন, `ঢাবি` → শাহবাগ, `NSU` → বসুন্ধরা

```bash
python 05_charts.py          # বিআরটিএ-র PDF → ছবি
python 06_match_charts.py    # কোন বাসের কোন চার্ট
python 08_merge_extra.py     # দ্বিতীয় উৎস থেকে বাড়তি বাস
python 09_chart_columns.py   # চার্টের কিমি কলাম কেটে আনা (পড়ে chart-stops.json)
python 10_resolve_charts.py  # চার্টের নাম → আমাদের স্টপেজ
python 04_build.py           # সব জোড়া দিয়ে site/data/data.json
```

`02d_validate.py` সবচেয়ে কাজের। এটাই ধরিয়ে দিয়েছে যে **কাকলী** শ্যামলীতে
বসে আছে, **কলেজ গেট** খিলগাঁওয়ে, আর **বিমানবন্দর** মহাখালীতে — কারণ ওসব
নামে ঢাকায় একাধিক জায়গা আছে। ঠিক করা অবস্থানগুলো `tools/overrides.json`-এ,
প্রতিটার পাশে কেন বদলানো হলো তা লেখা।

## যা এখনো ঠিক নয়

- **রুটের ডেটা পুরোনো।** busroutebd-র স্ক্র্যাপ কয়েক বছর আগের; অনেক বাস
  এখন আর চলে না। টাটকা কোনো উৎস নেই — তাই যাত্রীদের ভোটই ভরসা। ভোট জমতে
  সময় লাগবে, ততদিন তালিকা ধরে চললে ভুল হতে পারে।
- যেখানে সরকারি চার্ট আছে সেখানে ভাড়া হুবহু। বাকি জোড়ায় কিলোমিটার-হারে
  হিসাব — চার্টের চেয়ে গড়ে ১৩% এদিক-ওদিক হতে পারে।
- রিভিউ কেউ যাচাই করে না। আপাতত কোনো moderation নেই — বাজে লেখা এলে হাতে
  মুছতে হবে (Firebase Console থেকে)।
- ১১২টা সরকারি চার্টের মধ্যে ৩৩টা কাজে লেগেছে। বাকিগুলোর দুই প্রান্তের নাম
  আমাদের স্টপেজ তালিকায় নেই (ইপিজেড, কাপাসিয়া, ইকুরিয়া…)।
- নীলা মার্কেট, জারুন, কুচিমুড়া — OpenStreetMap-এ নেই, তাই বাদ পড়েছে।
  অনুমান করে কোঅর্ডিনেট বসানো হয়নি।
